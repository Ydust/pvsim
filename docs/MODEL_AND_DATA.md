# 数字孪生模型:构建思路、数据来源与数据表

本文梳理光伏物理数字孪生的**逐模块构建思路**、**三层验证**、**四层数据来源**与**核心数据表**,
供方法学复现与投稿 Methods 撰写。对应代码在 `pvsim/`,参数在 `pvsim/materials.py` /
`pvsim/policy_data.py`,数据溯源详见 `docs/DATA_PROVENANCE.md`。

**研究范围**: 本模型用于中国陆域光伏评估, 覆盖陆上地面集中式与屋顶/分布式场景。ERA5-Land
网格、土地惩罚和省级装机错配均是陆域口径; 海上或水面漂浮光伏因热边界、腐蚀/湿热可靠性、平台
与运维成本不同, 不在本文主模型中显式建模。

---

## 一、总体架构(从气象到度电成本的物理链)

```
 气象时间序列 (8760h: GHI/DNI/DHI, 气温, 风速, 太阳几何)
        │
   [POA 倾斜辐照]  pvlib 传输模型
        │
  ┌─────┴─────┬──────────┬───────────┐
[入射角 IAM] [双面增益] [光谱失配 SF] [Faiman 电池温度]
 Martin-Ruiz  视角因子   SPECTRL2+EQE   T_cell=f(POA,Tair,风)
        │
   有效辐照 eff = POA · IAM · (1+双面) · SF
        │
  [单二极管 De Soto 5 参数]  ← I0(T) 物理律(Ea_recomb)→ 温度系数自然产生
        │  Lambert-W 求解 I-V → MPP
   [组件/阵列装配] 串并联缩放 + 失配损失 + 直流损失
        │
   [PVWatts 逆变器] 直流→交流, dc/ac=1.2 高辐照削顶
        │
   交流发电 8760h → 比发电(kWh/kWp)、每 m²、PR
        │
  [退化/寿命] 逐年衰减 + burn-in
        │
  [NPV LCOE] 折现度电成本
        │
  [替代/经济] Wright 学习曲线 + 概率化择优 + 1000 次蒙特卡洛
```

**设计原则**:每一环都是**可分离、可开关**的物理子模型(见 `SystemConfig` 旋钮),
使"优势"可按机制(温度/光谱/光学)做反事实分解。同一台孪生支撑全部图与结论。

## 二、逐模块构建思路

### 1. 单二极管 De Soto 5 参数核心 (`pvsim/cell.py`)
电池 I-V:`I = I_L − I_0·[exp((V+I·R_s)/(n·V_th)) − 1] − (V+I·R_s)/R_sh`。
五参数(单电池 @STC):光生电流 `I_L`、反向饱和电流 `I_0`、串联电阻 `R_s`、
并联电阻 `R_sh`、理想因子 `n`。用 **Lambert-W** 解析求 I(V),再扫 V 取 MPP(`operating_point`)。
- 来源:De Soto et al., *Solar Energy* 2006。

### 2. 参数随工况 (G, T) 平移
`I_L(G,T)=I_L_ref·(G/G_ref)·[1+α_sc(T−T_ref)]`;`R_sh(G)=R_sh_ref·(G_ref/G)`;
`n·V_th` 随 T 线性;带隙 `Eg(T)=EgRef+dEgdT·(T−T_ref)`。

### 3. I0(T) 物理律 —— 温度系数的来源(关键)
`I_0(T)=I_0_ref·(T/T_ref)³·exp[(E_a/k)(1/T_ref − 1/T)]`,其中 **E_a=Ea_recomb 复合激活能**
**与光学带隙解耦**。物理含义:钙钛矿陷阱/界面复合 `Ea<Eg` → I0(T) 升得慢 → Voc(T) 降得慢
→ **温度系数 γ 小**。各技术的 `Ea_recomb` 由文献 γ **反标定**得到(非独立实测),
故温度系数是被**重现**而非强加。
- 这是本孪生区别于"硬塞 γ"模型的核心:γ 是物理涌现量。

### 4. Faiman 电池温度 (`pvsim/temperature.py`)
`T_cell = T_air + POA/(u0 + u1·风速)`,默认 `u0=25, u1=6.84 W·m⁻²·K⁻¹`(开放支架)。
- 来源:Faiman, *Prog. Photovolt.* 2008。

### 5. 光谱失配 SF (`pvsim/spectral.py`)
`SF = [J_ph(光谱)/G_宽谱] / [J_ph(AM1.5G)/1000]`。`J_ph ∝ ∫ EQE(λ)·E(λ)·λ dλ`,
EQE 用梯形近似(蓝端上升 + 平台 + 带隙 `λ_gap=1240/Eg` 锐截止)。任意天顶角光谱由
**SPECTRL2(Bird & Riordan)晴空模型**生成,按天顶角制 13 点查表插值(避免逐时跑 SPECTRL2)。
参考谱 **ASTM G173-03 AM1.5G**(pvlib)。
- 注意:SPECTRL2 为 **clear-sky** → 光谱机制驱动是太阳几何/大气质量,**不含云致蓝移**。

### 6. 入射角损失 IAM / 7. 双面增益 / 8. 逆变器
- IAM:Martin-Ruiz 模型(`pvsim/optics.py`)。
- 双面:视角因子模型,`albedo=0.2, rear_view=0.4`(单面技术 bifaciality=0 → 无增益)。
- 逆变器:**PVWatts**,`dc/ac=1.2`(高辐照削顶 clipping),标称效率 0.96;另含直流损失 5%、失配 2%。

### 9. 退化/寿命 → 10. NPV LCOE
逐年保持率 `(1−burn)·(1−deg)^(t−1)`;`LCOE = [capex·(1+Σ opex·df)] / Σ(yield·yf·df)`,
折现率 5%、运维 1.5%。

### 11. 替代/经济模型 (`scripts/fig_substitution_*`)
Wright 学习曲线 `cost(Q)=cost₀·(Q/Q₀)^(−b)`,`b=−log₂(1−LR)`;全国按各技术 LCOE 做
**概率化择优(softmax)分配**,用 2015–2023 多晶→单晶切换校准(R²=0.83);学习由**外生全球
进度**驱动以防锁定;**1000 次蒙特卡洛**覆盖学习率/成本下限/突破年/寿命/择优强度。

## 三、三层验证

| 层级 | 对象 | 结果 |
|---|---|---|
| 数值自洽 | vs pvlib `calcparams_desoto`+`singlediode`(126 工况×3技) | 最大偏差 **0.0007%** |
| 双实现 | Python ↔ 独立 C# 实现(交互模拟器) | **逐比特一致** |
| **系统级地面锚定** | vs 版本化机队利用小时代表表, 单位为 kWh/kWp/年, 覆盖 31 省 | **r=0.89**,系统性高 ~15%; 残差反演西北弃光 |

前两层证"算得对";第三层证空间型态"对得上现实",但它包含 BOS、弃光、调度与运维等系统因素,
不应解读为纯器件物理验证。

## 五、已知局限(诚实)

1. **晴空光谱**:SPECTRL2 不含云致光谱改变;光谱机制归因于太阳几何而非云量。
2. **气象为再分析/卫星**:非地面站实测(业界标准,但属"观测类"非"地面点测")。
3. **Ea_recomb 为反标定量**:由文献 γ 反推,非独立测量。
4. **情景参数(Tier 4)是前瞻假设**:仅以 P10-P90 情景区间报告,绝不报确定性点预测。
5. **降阶网格模型**:对 31 省 8760h 全模型的优势验证为 R²≈0.38、RMSE≈0.96 个百分点,
   因此只用于空间型态和全国反相关, 不用于单格点精确预测; 资源带机制强弱以省级 full-8760h
   分解为准。
6. **最优带隙对中国气候稳健**(细致平衡测得单结~1.40、叠层顶~1.74 eV 几乎不变)——
   "因地制宜带隙"在中国不成立(全球版可能不同)。
7. **不显式建模海上/水面漂浮光伏**:水体/海上环境可能降低组件温度、改变风冷与湿热/盐雾可靠性,
   且平台和运维成本不同;本文结论只直接适用于陆域光伏。
