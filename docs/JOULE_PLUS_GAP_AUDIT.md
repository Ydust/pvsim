# Joule-plus Gap Audit

本文件把当前论文按高于常规 Joule 投稿的标准审查。这里的目标不是达到可投, 而是达到强审稿人也很难把主结论打掉。

当前判断: 主线和开放源证据包已经达到 Joule-plus 可防守投稿状态。仍需在正文和 SI 中清楚限定, 本研究已经补入公司样本级空间实测 PV 绝对发电层, 但没有声称完整政府逐省 PV 绝对发电量清单已经获得。

## 最短攻关路线

1. 已把 62 行省级 release gate 改为 31 行官方装机加 31 行官方 PV 发电利用率, 严格审计通过。
2. 已增加国家统计局逐省总发电量层, 作为带空间轴的绝对发电量背景。
3. 已增加三峡能源经营地区 PV 发电量样本, 作为带空间轴的 PV-specific 绝对实测发电层。
4. 保留完整政府逐省 PV 绝对发电量清单为未来更强验证目标, 正文不得把总发电量层或公司样本层写成全国逐省 PV 发电量清单。
5. 继续扩展 MC prior appendix。
6. 准备外部数据和代码发布包。

完成前两项后, 源数据和开放外部验证已经达到当前可公开复核版本的 Joule-plus 防守线。
