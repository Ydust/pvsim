# 模型架构与计算逻辑系统梳理

最后更新：2026-07-05

文件用途：本文档系统整理本研究数字孪生模型的总体架构、各环节计算逻辑、输入输出关系、验证路径和经济替代计算。它是 Methods、SI 模型说明和代码复现之间的技术索引。

## 一、总体模型目标

模型目标不是预测某个电站的逐点发电量，而是在同一物理框架下比较现代硅、单结钙钛矿和钙钛矿硅叠层在中国陆域气候中的相对场发电表现，并将该物理优势传递到经济性和部署判断。

模型回答四个问题。

| 问题 | 对应模型层 | 输出 |
| --- | --- | --- |
| 钙钛矿相对现代硅在哪里更有优势 | 省级 8760 小时锚点和 0.1 degree 网格 | 空间优势图和资源带统计 |
| 优势来自什么物理机制 | 反事实开关分解 | 温度项、光谱项、IAM 残差 |
| 标准测试效率是否能代表场发电 | 技术性能标尺转换 | per kWp 和 per square metre 排名 |
| 物理优势何时变成经济替代 | LCOE、学习曲线和 softmax 替代 | 交叉年份分布和部署建议 |

## 二、总计算链条

模型从天气到发电，再到经济性和替代。

```text
天气时间序列
  -> 太阳几何和组件面辐照
  -> 入射角修正、双面增益、光谱失配
  -> 有效辐照
  -> Faiman 电池温度
  -> De Soto 五参数单二极管模型
  -> Lambert W 求解 IV 曲线和最大功率点
  -> 组件和阵列缩放
  -> PVWatts 逆变器和系统损失
  -> 8760 小时 AC 发电量
  -> 年度比发电量、PR、单位面积发电量
  -> 机制分解和空间统计
  -> 退化、寿命、折现电量和 LCOE
  -> 学习曲线、Monte Carlo 和替代情景
```

这个链条的核心原则是同址、同天气、同系统设置比较不同技术。这样得到的是技术相对优势，而不是不同地点或不同系统设计混在一起的绝对差异。

## 四、天气和辐照计算

### 4.1 天气输入

省级高保真仿真使用 PVGIS 典型气象年逐时数据，包含 GHI、DNI、DHI、气温、风速和太阳位置相关信息。空间格局图使用 ERA5-Land 气候态降阶层，包含地表短波辐射、2 m 气温和风速变量。

### 4.2 太阳几何

模型根据位置、日期和时间计算太阳天顶角、方位角和空气质量。空气质量是光谱机制的重要驱动量。所有机制驱动量在统计时按辐照加权，避免夜间或低功率时段支配结果。

### 4.3 组件面辐照

水平辐照被转置到倾斜组件平面，得到 POA 辐照。该步骤使相同天气可以进入不同安装几何。主要比较保持系统设置一致，以突出技术差异。

## 五、光学和光谱模块

### 5.1 IAM 入射角修正

入射角修正使用 Martin-Ruiz 模型。它描述太阳光斜入射时的有效透过损失。IAM 残差在机制分解中单独保留，不与温度或光谱项混合。

### 5.2 双面增益

双面增益使用视角因子近似，由反照率、背面可见性和双面率控制。单面技术双面率为零。默认比较中双面不是钙钛矿优势主因。

### 5.3 光谱失配

光谱失配因子由 SPECTRL2 晴空光谱与各技术 EQE 曲线积分得到，再用 AM1.5G 标准谱归一化。钙钛矿较宽带隙使其在低空气质量、偏蓝光谱下具有相对增益。

该模块只表达晴空太阳几何和空气质量效应。云量通过宽带辐照和温度进入模型，不通过云致蓝移进入主机制。

## 六、电池温度模块

电池温度由 Faiman 模型计算。核心逻辑是组件温升等于 POA 辐照除以由自然和风致散热组成的等效散热项。

```text
Tcell = Tair + POA divided by u0 plus u1 times wind speed
```

温度模块把气象差异传递到电学模型。钙钛矿优势的重要部分来自较高 Tcell 条件下较小功率温度损失。

## 七、单二极管电学模块

### 7.1 De Soto 五参数模型

电池 IV 曲线由光生电流、反向饱和电流、串联电阻、并联电阻和理想因子控制。模型在给定有效辐照和电池温度下更新参数，再用 Lambert W 求解 IV 曲线和最大功率点。

### 7.2 温度系数的来源

功率温度系数不是简单硬加的后处理项。模型通过饱和电流随温度变化的物理律复现文献温度系数。`Ea_recomb` 是由文献 gamma 反标定的复合激活能，不是独立实测输入。这样温度系数成为电学模型的涌现量。

### 7.3 技术参数

| 技术 | 角色 | 关键设定 |
| --- | --- | --- |
| 现代硅 | 主基准 | 约 22 percent STC 效率，约 -0.32 percent per C |
| 单结钙钛矿 | 主要替代技术 | 约 19.3 percent STC 效率，约 -0.15 percent per C |
| 钙钛矿硅叠层 | 面积受限技术 | 约 28.3 percent STC 效率，约 -0.30 percent per C |
| 早期硅 | 历史参考 | 不作为主对照 |

现代硅是主基准，因为它最接近当前新增装机技术状态。

## 八、系统输出模块

电池和组件功率经过串并联缩放形成阵列输出，再经过直流损失、失配损失、逆变器效率和削峰。逆变器使用 PVWatts 逻辑。输出包括逐时 AC 功率、年度比发电量、性能比和单位面积发电量。

三个关键性能标尺如下。

| 标尺 | 计算逻辑 | 用途 |
| --- | --- | --- |
| STC 效率 | 标准测试功率除以面积和标准辐照 | 名义效率比较 |
| 年度单位装机发电量 | 年 AC 发电量除以额定 kWp | 地面电站经济比较 |
| 年度单位面积发电量 | 年 AC 发电量除以组件面积 | 屋顶和面积受限比较 |

这就是为什么钙钛矿可在 per kWp 标尺上优于现代硅，而叠层主要在 per square metre 标尺上优于其他技术。

## 九、机制分解逻辑

机制分解通过反事实开关完成。

| 分量 | 计算方法 | 解释 |
| --- | --- | --- |
| 光谱项 | 完整运行减去平坦光谱运行 | 由带隙、EQE 和空气质量造成的差异 |
| 温度项 | 技术温度系数差作用于能量加权 Tcell 偏离 | 由温度损失差异造成的差异 |
| IAM 残差 | 无光谱运行减去无光谱无 IAM 运行 | 由入射角光学造成的差异 |
| 总优势 | 钙钛矿年发电量除以现代硅年发电量再减一 | 技术相对场发电优势 |

温度项与辐照加权电池温度相关，光谱项与辐照加权空气质量相关。两者在空间上共同增强了西南和华南优势，在时间上则表现为温度项夏季增强、光谱项全年存在。

## 十、网格降阶和不确定性

完整 8760 小时模型对 31 个省级锚点运行。0.1 degree 网格使用 ERA5-Land 气候态降阶层，以锚点关系校准。降阶层的目标是恢复空间型态和区域排序，而不是给出逐格点场站预测。

当前降阶优势变量验证结果如下。

| 指标 | 数值 |
| --- | ---: |
| R2 | 0.377 |
| RMSE | 0.962 percentage points |
| 中位绝对误差 | 0.703 percentage points |
| P90 绝对误差 | 1.444 percentage points |
| 最大省级误差 | 2.532 percentage points |
| 网格辐照和优势关系 | r = -0.514 |

因此主图 Fig 1 表达空间反转和区域排序。省级精确数值以 8760 小时锚点为准。

## 十二、经济性计算逻辑

### 12.1 LCOE

LCOE 由折现成本除以折现发电量。成本包括初始 capex 和按 capex 比例计算的年度运维。发电量包括首年产出、burn-in、年度退化和寿命。

```text
LCOE = discounted cost divided by discounted lifetime generation
```

寿命、退化和 capex 对 LCOE 的影响大于钙钛矿约 3 percent 的发电优势。因此经济主结论是寿命门槛，而不是单纯 yield 优势。

### 12.2 学习曲线

技术成本随累计部署按 Wright 学习曲线下降。学习率越高，累计部署翻倍后的成本下降越快。未来成本下限和学习率都进入 Monte Carlo。

### 12.3 替代分配

新增装机在技术之间通过 softmax merit-order 分配。较低 LCOE 技术获得更高份额，但模型允许共存和惯性。该分配用 2015 至 2023 年中国多晶硅向单晶硅切换历史校准，R2 约为 0.83。

### 12.4 Monte Carlo

Monte Carlo 覆盖学习率、成本下限、突破年份、突破后寿命、退化和选择锐度。输出为交叉年份分布而不是预测点。当前 P10、P50、P90 交叉年份为 2030、2032 和 2039，另有 2.7 percent 抽样到 2050 年仍不交叉。

## 十三、部署计算逻辑

部署判断由三类量组合。

| 量 | 计算或来源 | 解释 |
| --- | --- | --- |
| 钙钛矿 per kWp 优势 | 省级模型输出 | 陆域地面电站技术收益 |
| 2024 省级装机 | NEA 省级装机源表 | 当前部署权重 |
| 土地惩罚 | 纬度和行距几何 | 高纬地面电站自遮挡和行距成本 |

Fig 5 的结论是部署错配：高钙钛矿优势三分位省份只拥有约 24 percent 2024 装机，而中间和低优势省份拥有更多装机。高纬西北有高绝对辐照，但 per kWp 相对优势较小，土地惩罚较高，因此不应只按辐照强度决定钙钛矿首发部署。

## 十四、主结论怎样从计算链条推出

| 主结论 | 由哪些环节推出 |
| --- | --- |
| 弱日照区钙钛矿相对收益最高 | 8760 小时发电模型、0.1 degree 空间层、温度和光谱反事实 |
| 反转由温度和空气质量光谱共同驱动 | Faiman 温度、SPECTRL2 光谱、机制分解和偏相关 |
| 效率评级会误判场发电 | STC、per kWp 和 per square metre 三标尺比较 |
| 替代首先受寿命控制 | LCOE 分解、寿命退化敏感性、Monte Carlo |
| 部署应按物理而非辐照直觉 | 省级优势、装机份额、纬度土地惩罚和 Fig 5 决策平面 |
